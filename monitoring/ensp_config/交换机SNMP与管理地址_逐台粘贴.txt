# 二层交换机 SNMP + 管理地址 逐台粘贴脚本
# ------------------------------------------------------------
# 背景：所有 S5700 的 flash.efz 为空（从未 save），无法直接写文件，
#       必须在 eNSP 运行时逐台打开 CLI 粘贴，最后 save。
#
# 统一规划：
#   管理 VLAN = 88，VLANIF88 落在 192.168.88.0/24
#   与防火墙 GE0/0/0 带外管理口同网段，监控主机（经 Cloud 接入）直达
#   community = Monitor@123（与 exporter/devices.yaml 一致）
#
# 注意：
#   1) 每台交换机的【上联口】要放行 VLAN 88（脚本中默认 GE0/0/1，
#      请按实际接线改成真正的上联口！）
#   2) 监控主机若不在 192.168.88.0/24 网段，才需要脚本中的默认路由
#   3) 粘贴完务必 save，否则重启丢失
#   4) 每台末尾的 trap target-host 指向监控主机（默认 192.168.88.10，
#      请按实际监控主机在 eNSP Cloud 中的 IP 修改）
# ============================================================

sysname CORE1
vlan 88
interface Vlanif88
 ip address 192.168.88.21 255.255.255.0
interface GigabitEthernet0/0/1
 port link-type trunk
 port trunk allow-pass vlan 88
snmp-agent
snmp-agent community read cipher Monitor@123
snmp-agent sys-info version v2c
snmp-agent target-host trap address udp-domain 192.168.88.10 params securityname Monitor@123 v2c
save
